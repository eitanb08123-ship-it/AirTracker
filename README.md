# AirTracker

אפליקציית Android למציאת AirPods בלי אייפון. Kotlin + Jetpack Compose + Material 3, ממשק בעברית.

## הורדה

**[הורד את ה-APK האחרון](https://github.com/eitanb08123-ship-it/airtracker/releases/latest/download/AirTracker.apk)**

או בעמוד ה-[Releases](https://github.com/eitanb08123-ship-it/airtracker/releases/latest).

התקנה: פתח את הקובץ שהורדת, אשר "התקנה ממקורות לא ידועים" לדפדפן, והתקן.

## מה יש

- **חץ ניווט** אל המיקום האחרון שבו הטלפון זיהה את האוזניות (GPS + מצפן + חיישני תנועה), עם מרחק.
- **מד קרבה** לפי עוצמת אות ה-Bluetooth, כשהאוזניות משדרות. זו אינדיקציה בלבד, לא מרחק ולא כיוון.
- **איתור Bluetooth**: מכשירים מותאמים, שידורי AirPods ציבוריים (BLE), וכל מכשירי ה-BLE בסביבה.
- **צפצוף מרמקול הטלפון** כשהאות עובר סף שבוחרים, עם השהיה בין צפצופים ומניעת חזרות.
- **מפה** (OpenStreetMap) עם היסטוריית מיקומים, תאריך ושעה, ואזהרות על מיקום ישן או לא מדויק.
- **מעקב ברקע** (Foreground Service) ושמירת מיקום והתראה כשהאוזניות מתנתקות.
- **סוללה** משוערת (שמאל/ימין/קופסה) מתוך השידור, כשזמין.
- מצב כהה, אנימציות, עיצוב בהשראת Find My.

## מגבלות (אמיתיות)

- אין גישה לרשת Find My של Apple. אין לכך API רשמי באנדרואיד, והאפליקציה לא משתמשת ב-API פרטי.
- אי אפשר להשמיע צליל מתוך האוזניות.
- AirPods בתוך קופסה סגורה בדרך כלל לא משדרות, לכן מוצג המיקום האחרון הידוע.
- כתובת ה-BLE של AirPods מתחלפת, לכן הזיהוי ב-BLE לפי דגם. אוזניות של אחרים מאותו דגם יכולות להופיע.
- ערכי הסוללה מפוענחים מפורמט שתועד על ידי הקהילה ולכן משוערים.

## בנייה

GitHub Actions בונה APK בכל push ל-`main` ומפרסם אותו ב-Releases (`.github/workflows/build-apk.yml`).

חתימה: אם מוגדרים secrets בשם `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, ה-APK נחתם במפתח קבוע. בלעדיהם הוא נחתם במפתח debug זמני של כל בנייה, ולכן עדכון לגרסה חדשה ידרוש להסיר קודם את הגרסה הקודמת.
